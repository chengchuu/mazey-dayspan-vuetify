# Roadmap to 1.0

1. Harden recurrence across DST, end-of-month policies, time zones, and property-based tests.
2. Add accessible pointer drag/move and resize with keyboard equivalents and cancellable hooks.
3. Expand occurrence-management UI for inclusions, exclusions, cancellation, and moves.
4. Add focus-trapped event popovers, roving grid focus, screen-reader testing, and axe checks.
5. Test SSR, publish browser support targets, run cross-browser Playwright, and stabilize APIs.
6. Add an optional RFC 5545 import/export adapter without leaking it into the view layer.
